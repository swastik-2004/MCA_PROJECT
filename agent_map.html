The four words to explain
A2A (Agent2Agent)

An open protocol for agents to send each other tasks over the network, like messaging between team members. Each of our agents is its own small server.

Agent Card

Each agent's public ID card: its name, what it can do (skills) and its address. The Director reads the cards to find the team.

MCP (Model Context Protocol)

A standard plug for AI tools. Our digital twin is one MCP server with 10 tools, so any agent, or Claude Desktop, can use it.

Master–worker

A boss process splits the simulations into small chunks and hands them to worker processes. If a worker crashes, its work is redone by a replacement.
