HOW TO PLAY

Goal: reach the glowing extraction portal. Some levels need the magenta keycard to open the blast door first.

Hunter drones chase you and shoot back. Proximity mines blink red; shoot them from a distance to detonate them safely. Med-kits restore integrity; data cores are optional score.

Controls: WASD move · mouse aim · click/hold fire · SPACE dash (brief invulnerability) · R reload · ESC pause · M music.

The game uses the same values as the AI's digital twin: you start with the same health, drones have the same health, mines and med-kits do the same damage and healing. The twin is a simplified turn-based model of this game.
